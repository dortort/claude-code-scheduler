# Artifact Callbacks 0.1.1

Clarifies installation requirements and when to choose the mod or its channel alternative.

- Documents Claude Code 2.1.287+ in the terminal, or bundled Claude Code 2.1.286+ in Desktop's Code tab, and Node.js 22.18+.
- Explains the confirm band, per-click turns, reply streaming, and local-session requirements.
- Makes the choice between variants explicit: enable only one per session.
- Adds an independent release process and versioned release notes.

This release keeps the existing callback behavior. It needs no npm package or build step.

Update:

```bash
claude plugin marketplace update dortort
claude plugin update artifact-callbacks@dortort
```

Run `/reload-plugins` or restart Claude Code after updating.
