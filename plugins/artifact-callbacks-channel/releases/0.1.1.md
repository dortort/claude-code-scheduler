# Artifact Callbacks Channel 0.1.1

Clarifies the channel alternative's requirements and reports the installed plugin version in the MCP handshake.

- Reads the MCP server name and version from the plugin manifest so the reported versions stay aligned.
- Explains when to choose the channel instead of the mod, including its different event and reply behavior.
- Documents the lack of a confirm band and remote/SSH checks.
- Adds an independent release process and versioned release notes.

This remains a channels research-preview plugin. It requires Node.js 22.18+, Anthropic authentication, and channel access permitted by your organization. Publishing this release does not put it on Anthropic's channel allowlist. Unless your organization allowlists it, start an interactive session with the development flag:

```bash
claude plugin marketplace update dortort
claude plugin update artifact-callbacks-channel@dortort
claude --dangerously-load-development-channels plugin:artifact-callbacks-channel@dortort
```

Enable only this variant or the mod in a session, never both. No npm publishing or build step is required.
